Piezoelectric Energy Prediction

Hybrid machine learning and DFT-based framework for
piezoelectric energy harvesting using ZnO and Fe-doped ZnO.

Features

• Real-time voltage prediction
• Gradient Boosting ML model
• DFT analysis
• Gaussian simulations
• MATLAB post-processing
• Flask dashboard
• IoT-enabled sensing

data/

static/

Requirements

Python 3.11

pip install -r requirements.txt

Run

python app.py
